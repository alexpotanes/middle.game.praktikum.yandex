### Общая концепция

War Chest — это тактическая абстрактная игра с механикой bag-building (построение мешка), где игроки выступают в роли средневековых командиров, борющихся за контроль над тактическими точками на поле боя.

**Для просмотра схемы необходимо поставить плагин mermaid**

### Компоненты игры

1. Игровое поле

   - Гексагональная сетка (шестиугольники)
   - Специальные клетки-локации отмечены зелёным узором (control points)
   - Каждая сторона имеет 2 стартовые локации

2. Фишки-монеты (Unit Coins)

   - 16 типов юнитов в базовой игре
   - Каждый тип юнита представлен 4-5 фишками
   - Фишки качественные, тяжёлые, похожи на монеты
   - Королевская монета (Royal Coin) — специальная фишка без юнита

3. Карты юнитов (Unit Cards)

   - Описывают характеристики и способности каждого типа юнита
   - Показывают тактическую способность (Tactic)
   - Указывают количество фишек юнита (4 или 5)

4. Мешки (Bags)

   - Каждый игрок имеет мешок для хранения своих монет
   - Из мешка вытягиваются монеты в начале каждого раунда

5. Маркеры контроля (Control Markers)

   - По 6 маркеров на игрока
   - Размещаются на локациях для обозначения контроля

6. Маркер инициативы (Initiative Marker)
   - Определяет, кто ходит первым в раунде

### Настройка игры (Setup)

1. Каждый игрок выбирает фракцию
2. Получает: 1 мешок, 1 Королевскую монету, 6 маркеров контроля
3. Размещает по 1 маркеру контроля на своих стартовых локациях
4. Получает 4 случайные карты юнитов
5. По 2 монеты каждого типа юнита кладёт в мешок вместе с Королевской монетой
6. Остальные монеты формируют резерв (supply pile)
7. Бросается маркер инициативы для определения первого игрока

### Условие победы

Первый игрок, разместивший все 6 своих маркеров контроля на локациях, побеждает.

### Структура хода

Фаза 1: Вытягивание монет (Draw Coins)

- Каждый игрок вытягивает 3 монеты из своего мешка
- Монеты держатся в руке скрыто от противника
- Когда мешок пустеет, сброс перемешивается и становится новым мешком

Фаза 2: Использование монет (Use Coins)

- Игроки по очереди выполняют действия (начинает владелец инициативы)
- За ход используется 1 монета
- Продолжается до тех пор, пока у обоих игроков не закончатся монеты

### Доступные действия

#### Действия с размещением монет лицом вверх на поле:

1. Deploy (Развёртывание)

   - Разместить монету юнита на пустую локацию под вашим контролем
   - Только один юнит каждого типа может быть на поле одновременно

2. Bolster (Укрепление)
   - Добавить монету поверх уже размещённого юнита того же типа
   - Увеличивает прочность юнита (защита от атак)

#### Действия со сбросом монеты лицом вниз (скрыто):

1. Claim Initiative (Захват инициативы)

   - Взять маркер инициативы (будете ходить первым в следующем раунде)

2. Recruit (Рекрутирование)

   - Взять новую монету из резерва и положить в сброс
   - Увеличивает количество монет в вашем мешке

3. Pass (Пас)
   - Пропустить оставшиеся действия в раунде

#### Действия со сбросом монеты лицом вверх (манёвры):

1. Move (Движение)

   - Переместить юнит на одну клетку в соседний пустой гекс
   - Требует сбросить монету, соответствующую юниту на поле

2. Control (Контроль)

   - Разместить маркер контроля на нейтральной или вражеской локации
   - Юнит должен находиться на этой локации
   - Можно захватывать вражеские локации

3. Attack (Атака)

   - Убрать одну монету с соседнего вражеского юнита
   - Если у юнита была только одна монета, он уничтожается
   - Уничтоженные монеты возвращаются в коробку (не в резерв!)

4. Tactic (Тактика)
   - Использовать специальную способность юнита
   - Каждый тип юнита имеет уникальную тактическую способность

### Механика боя

- Атака убирает одну монету с вражеского юнита
- Юниты с несколькими монетами (bolstered) могут выдержать несколько атак
- Уничтоженные монеты выходят из игры навсегда
- Юниты могут быть развёрнуты заново, если у вас остались их монеты в мешке/резерве

#### Асимметричность и реиграбельность

- В каждой партии используется только 8 из 16 типов юнитов
- Каждая сторона получает 4 случайных юнита
- Юниты имеют уникальные способности (тактики)
- Создаёт огромную вариативность между партиями

#### Специальные правила

- Королевская монета не имеет соответствующего юнита
- Может использоваться только для действий со сбросом лицом вниз
- Только один юнит каждого типа может быть развёрнут одновременременно
